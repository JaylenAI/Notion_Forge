# Content Writing Skill

Controls the tone, style, and quality of all text content inside generated Notion templates.

## Writing Principles

### 1. Tone & Style
- Friendly but professional
- Use emoji sparingly and purposefully
- Short, clear sentences
- Default language: Korean. English terms OK when natural

### 2. Callout Writing
- First line = core message
- Icon indicates purpose: 💡 tip, 📌 important, ⚠️ warning, 👋 welcome
- Background color matches template theme

### 3. Heading Writing
- heading_1: Main section title (emoji + text)
- heading_2: Sub-section title
- heading_3: Detail item

### 4. Sample Data Rules
- Must look like real usage (not obviously fake)
- Cover diverse statuses (not started / in progress / done)
- Each item gets a relevant icon
- Dates realistic (±2 weeks from creation)
- Include 4-7 items per database

### 5. FAQ Writing
- Questions people would actually ask
- Answers in 1-2 sentences
- Use toggle blocks

### 6. Empty State
- Good: "No items yet. Add your first one! ✨"
- Bad: "No data"

### 7. Welcome Message
- Good: "Welcome! Manage all your team projects at a glance."
- Bad: "This is a project management page."
