# NotionForge 기획서

## 1. 프로젝트 소개

### 프로젝트명
**NotionForge** - AI 기반 노션 템플릿 자동 생성 에이전트

### 소속
가짜연구소 - "나만의 자동화 AI Agent 만들기" 프로젝트

### 한 줄 요약
> 사용자가 채팅으로 원하는 템플릿을 설명하면, AI가 Notion API를 통해 완성된 노션 워크스페이스를 자동 생성해주는 오픈소스 에이전트

---

## 2. 기획 의도

### 문제 정의 (Pain Point)

노션 템플릿 제작은 **반복적이고 시간이 많이 소요**되는 작업이다:

| 작업 | 소요 시간 | 특징 |
|------|-----------|------|
| 구조 설계 (페이지 계층, DB 스키마) | 30분~1시간 | 매번 비슷한 패턴 반복 |
| DB 속성 설정 (셀렉트, 관계형, 수식) | 20~40분 | 수동 클릭 노가다 |
| 뷰 구성 (갤러리, 칸반, 캘린더) | 10~20분 | 필터/정렬 반복 설정 |
| 디자인 (색상, 아이콘, 커버, 레이아웃) | 30분~1시간 | 시행착오 반복 |
| 샘플 데이터 입력 | 15~30분 | 단순 반복 |
| **총계** | **2~4시간 / 템플릿** | |

### 해결 방안

```
기존: 아이디어 → 수동 제작 (2~4시간) → 완성
개선: 아이디어 → AI 대화 (5분) → 자동 생성 (30초) → 미세 조정 (10분) → 완성
```

**시간 절약: 약 80~90%**

### 왜 이 프로젝트인가?

1. **실제 본인의 반복 작업** - 노션 마켓플레이스에 템플릿을 공유하며 인지도를 쌓고 있는 실제 크리에이터
2. **시장 공백** - AI 노션 템플릿 생성기는 현재 존재하지 않음 (Notion AI는 텍스트 생성만 가능)
3. **오픈소스 가치** - 노션 사용자 1억명+ 중 템플릿 제작자 수만명이 잠재 사용자
4. **명확한 산출물** - GitHub 레포 + 데모 사이트 + 시연 영상

## 3. 시장 조사

### 시장 규모

| 지표 | 수치 |
|------|------|
| Notion 전체 사용자 | 1억명+ (2025년 기준) |
| 템플릿 크리에이터 | 수만명 (공식 갤러리 + 외부 마켓) |
| 톱 크리에이터 연 매출 | $100K ~ $1M+ (Thomas Frank, Easlo 등) |
| 유료 템플릿 평균 가격 | $5 ~ $49 (프리미엄 $49 ~ $149) |

### 주요 마켓플레이스

| 플랫폼 | 특징 |
|--------|------|
| **Notion 공식 갤러리** | Creator Monetization Program, 수익 공유 |
| **Gumroad** | 가장 인기 있는 외부 판매 플랫폼 |
| **Etsy** | 디지털 제품 판매 성장 중 |
| **Prototion** | 노션 전용 마켓플레이스 |
| **Lemonsqueezy** | Gumroad 대안, 글로벌 결제 지원 |

### 인기 카테고리

```
1. 생산성/GTD (Second Brain, 습관 트래커)     → 수요: 매우 높음
2. 비즈니스/스타트업 (CRM, 프로젝트 관리)      → 수요: 매우 높음
3. 개인 재무 (가계부, 투자 포트폴리오)          → 수요: 높음
4. 콘텐츠 관리 (에디토리얼 캘린더, SNS 플래너) → 수요: 높음
5. 학생/학습 (강의 트래커, 스터디 플래너)      → 수요: 높음
6. 라이프스타일 (독서, 여행, 레시피)           → 수요: 중~높음
```

### 경쟁 분석

**직접 경쟁자 없음.** 이것이 핵심 기회.

| 도구 | 기능 | NotionForge와의 차이 |
|------|------|---------------------|
| **Notion AI** | 텍스트 생성, 요약, 번역 | 구조/템플릿 생성 불가. 콘텐츠만 생성 |
| **Gamma.app** | AI 프레젠테이션 생성 | 노션이 아닌 자체 플랫폼 |
| **v0.dev** | AI UI 코드 생성 | 웹 컴포넌트 전용, 노션 아님 |

### 경쟁 우위

1. **시장 최초 (First Mover)** - AI 노션 템플릿 생성기 분야에 경쟁자 부재
2. **실제 크리에이터 기반** - 본인이 직접 템플릿을 만드는 크리에이터이므로 니즈를 정확히 이해
3. **오픈소스** - 커뮤니티 기여로 패턴 라이브러리 확장 가능
4. **풀스택 자동화** - 텍스트만이 아닌 구조, DB, 뷰, 디자인까지 전체 자동화

### 시장 기회 요약

```
       시장 크기: ★★★★★ (1억+ 노션 사용자)
     경쟁 강도: ★☆☆☆☆ (직접 경쟁자 없음)
   기술 실현성: ★★★★☆ (API 제한 일부 있으나 핵심 기능 가능)
     차별화: ★★★★★ (최초의 AI 노션 템플릿 생성기)
 오픈소스 가치: ★★★★☆ (커뮤니티 수요 높음)
```

> Notion AI가 "텍스트를 써주는 AI"라면, NotionForge는 "워크스페이스를 만들어주는 AI"이다.

### 레퍼런스 프로젝트

| 프로젝트 | 참고 포인트 |
|----------|------------|
| **Gamma.app** | "자연어 → 구조화된 문서" 전환 UX |
| **v0.dev (Vercel)** | "자연어 → UI 코드" 생성 패턴 |

## 4. 타겟 사용자

### Primary: 노션 템플릿 크리에이터
- 마켓플레이스에 템플릿을 판매/공유하는 사람
- **핵심 가치**: 제작 시간 80% 단축

### Secondary: 노션 파워 유저
- 팀/회사 노션 워크스페이스를 구축해야 하는 담당자
- **핵심 가치**: 전문가 수준의 템플릿을 자동으로 받기

### Tertiary: 노션 입문자
- 노션을 시작했지만 어떻게 구성할지 모르는 사용자
- **핵심 가치**: AI 대화로 쉽게 워크스페이스 구축

## 5. 핵심 기능

### MVP (Phase 1)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 채팅 인터페이스 | 자연어로 템플릿 요구사항 입력 | P0 |
| 의도 분석 | AI가 사용자 요구를 구조화된 스펙으로 변환 | P0 |
| 페이지 생성 | 커버, 아이콘, 제목, 기본 블록 자동 생성 | P0 |
| DB 생성 | 데이터베이스 + 속성(셀렉트, 날짜 등) 자동 설정 | P0 |
| 레이아웃 구성 | 칼럼, 섹션, 네비게이션 배치 | P0 |
| 색상 테마 | 사용자 지정 색상 톤 적용 | P1 |
| 샘플 데이터 | 맥락에 맞는 예시 데이터 자동 입력 | P1 |

### 확장 (Phase 2)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 중첩 페이지 | 하위 페이지별 독립 구조 자동 구축 | P1 |
| Relation/Rollup | DB 간 관계 설정 자동화 | P2 |
| 커버 이미지 생성 | AI 이미지 생성으로 커스텀 커버 | P2 |
| 템플릿 패턴 라이브러리 | 사전 정의된 패턴 기반 빠른 생성 | P2 |

### 고도화 (Phase 3)

| 기능 | 설명 | 우선순위 |
|------|------|----------|
| 기존 템플릿 분석 | URL 입력 → 구조 분석 → 변형 생성 | P3 |
| 대화형 수정 | "DB에 태그 속성 추가해줘" 같은 후속 수정 | P3 |
| 다국어 지원 | 한국어, 영어, 일본어 템플릿 | P3 |

## 6. 프로젝트 범위 (Scope)

### In Scope
- Notion API로 생성 가능한 모든 블록 타입 활용
- 페이지, 데이터베이스, 블록, 칼럼 레이아웃
- 색상 테마, 아이콘, 커버 이미지 설정
- 채팅 기반 인터페이스 (웹)
- 오픈소스 (MIT License)

### Out of Scope
- Button 블록, Synced Block (Notion API 미지원)
- 결제/구독 시스템 (MVP 범위 아님)
- 모바일 앱

- GitHub Star 100개+ (프로젝트 종료 후 3개월 내)
- 템플릿 생성 성공률 90%+
- 평균 생성 시간 30초 이내 (단일 페이지)
