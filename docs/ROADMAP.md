# 로드맵 (Roadmap)

> NotionForge 향후 개발 방향

---

## v1.0 하드닝 게이트 (진행 중, 2026-05-30 기준)

실제 Notion 라이브 검증 기반으로 "기업급 구조 + 유료급 결과물 + 떳떳한 공개"를 목표로 게이트별 강화.

- [x] **Gate 0 — 공개 전 보안 차단**: gitleaks/pre-commit, custom_skills 위생, CI 전체 히스토리 스캔
- [x] **Gate 1 — Agent 안정성 봉합**: Provider Fallback·Approval Gate·비용통제 실배선, ADR 0001
- [ ] **Gate 2 — 템플릿 유료급 품질** (~55%): rollup/formula 실집계(dual_property)·SDK 버전핀·비용통제 ✅ / 멀티DB 기본화·advanced 골든셋·통화포맷·품질 스코어카드 잔여
- [ ] **Gate 3 — Notion API 완전성**: data_source 마이그레이션 완결, 페이지네이션, rate limiter jitter
- [ ] **Gate 4 — 테스트·관측성·회귀게이트**: CI 통합테스트 포함, diff-coverage, Playwright E2E, Prometheus/OTel
- [ ] **Gate 5 — 릴리스·DevOps·공급망**: 버전 SSOT, SBOM/cosign, 라이선스 호환 CI, semantic-release
- [ ] **Gate 6 — 커뮤니티·문서·UX → v1.0.0**: README 정직화, 거버넌스, a11y, 결정성 한계 명시

> 코드로 도달 가능한 천장 = "기업급 구조 + 유료급($20~30) 결과물 + 공개 가능한 v1.0". 최상위($50) 비주얼 디자인과 실시장 검증은 코드 외 영역.

---

## 단기 (1~2개월)

### 템플릿 품질 프리미엄화
- [ ] 프리미엄 템플릿 디자인 패턴 10종 추가 (대시보드, CRM, OKR 등)
- [ ] 커버 이미지 자동 생성 (Unsplash/DALL-E 연동)
- [ ] 템플릿 A/B 테스트 (같은 프롬프트 → 다른 디자인 비교)

### Agent 고도화
- [ ] 멀티턴 대화 맥락 개선 (장기 메모리 + 요약)
- [ ] Agent Loop 성공률 95%+ 달성
- [ ] 도구 실행 결과 자가 검증 강화

### 테스트 강화
- [ ] 프론트엔드 E2E 테스트 (Playwright)
- [ ] 실제 Notion API E2E 테스트 (샌드박스)
- [ ] 커버리지 85%+ 달성

### 프로덕션 배포
- [ ] Vercel (FE) + Railway (BE) 프로덕션 배포
- [ ] 시연 영상 + 발표 자료

## 중기 (3~6개월)

### 사용자 경험
- [ ] 템플릿 마켓플레이스 (커뮤니티 공유)
- [ ] 템플릿 버전 관리 (히스토리 + 롤백)
- [ ] 사용자 대시보드 (사용 통계, 즐겨찾기)

### AI 확장
- [ ] 자체 파인튜닝 모델 (비용 절감)
- [ ] 이미지 기반 템플릿 생성 ("이 스크린샷처럼 만들어줘")
- [ ] 자연어 수정 고도화 ("3번째 DB의 날짜 속성을 주간으로 바꿔줘")

### 인프라
- [ ] 분산 세션 관리 (Redis)
- [ ] 모니터링 대시보드 (Grafana + Prometheus)
- [ ] API Rate Limiting 고도화 (사용자별 티어)

---

## 장기 (6개월~1년)

### 플랫폼 확장
- [ ] Notion 외 플랫폼 지원 (Coda, Airtable)
- [ ] 플러그인/확장 시스템 (서드파티 스킬)
- [ ] REST API 공개 (외부 서비스 연동)

### 엔터프라이즈
- [ ] 팀/조직 워크스페이스 지원
- [ ] SSO 인증 (SAML, OIDC)
- [ ] 감사 로그 (Audit Trail)

### 커뮤니티
- [ ] 스킬 마켓플레이스 (사용자 제작 스킬 공유)
- [ ] 다국어 확장 (현재 한/영/일 → 10개 언어)
- [ ] 기여자 프로그램 (Contributor Recognition)
