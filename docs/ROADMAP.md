# 로드맵 (Roadmap)

> NotionForge 향후 개발 방향

---

## 단기 (1~2개월)

### 템플릿 품질 프리미엄화
- [ ] 프리미엄 템플릿 디자인 패턴 10종 추가 (대시보드, CRM, OKR 등)
- [ ] 커버 이미지 자동 생성 (Unsplash/DALL-E 연동)
- [ ] 템플릿 A/B 테스트 (같은 프롬프트 → 다른 디자인 비교)

### Agent 고도화
- [ ] 멀티턴 대화 맥락 개선 (장기 메모리 + 요약)
- [ ] Agent Loop 성공률 95%+ 달성
- [ ] 도구 실행 결과 자가 검증 강화

### 테스트 강화
- [ ] 프론트엔드 E2E 테스트 (Playwright)
- [ ] 실제 Notion API E2E 테스트 (샌드박스)
- [ ] 커버리지 85%+ 달성

### 프로덕션 배포
- [ ] Vercel (FE) + Railway (BE) 프로덕션 배포
- [ ] 시연 영상 + 발표 자료

---

## 중기 (3~6개월)

### 사용자 경험
- [ ] 템플릿 마켓플레이스 (커뮤니티 공유)
- [ ] 템플릿 버전 관리 (히스토리 + 롤백)
- [ ] 사용자 대시보드 (사용 통계, 즐겨찾기)

### AI 확장
- [ ] 자체 파인튜닝 모델 (비용 절감)
- [ ] 이미지 기반 템플릿 생성 ("이 스크린샷처럼 만들어줘")
- [ ] 자연어 수정 고도화 ("3번째 DB의 날짜 속성을 주간으로 바꿔줘")

### 인프라
- [ ] 분산 세션 관리 (Redis)
- [ ] 모니터링 대시보드 (Grafana + Prometheus)
- [ ] API Rate Limiting 고도화 (사용자별 티어)

---

## 장기 (6개월~1년)

### 플랫폼 확장
- [ ] Notion 외 플랫폼 지원 (Coda, Airtable)
- [ ] 플러그인/확장 시스템 (서드파티 스킬)
- [ ] REST API 공개 (외부 서비스 연동)

### 엔터프라이즈
- [ ] 팀/조직 워크스페이스 지원
- [ ] SSO 인증 (SAML, OIDC)
- [ ] 감사 로그 (Audit Trail)

### 커뮤니티
- [ ] 스킬 마켓플레이스 (사용자 제작 스킬 공유)
- [ ] 다국어 확장 (현재 한/영/일 → 10개 언어)
- [ ] 기여자 프로그램 (Contributor Recognition)
