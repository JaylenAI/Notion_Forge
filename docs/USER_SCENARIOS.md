# 유저 시나리오 (User Scenarios)

> 사용자가 NotionForge를 어떻게 사용하는지에 대한 상세 시나리오

---

## 1. 사용자 여정 (User Journey)

### 전체 플로우

```
접속 → 요구사항 입력 → AI 질문/확인 → 구조 확인 → 생성 시작 → 완성 링크 수신 → 미세 조정
```

### 상세 단계

| 단계 | 사용자 행동 | 시스템 응답 |
|------|------------|-----------|
| 1. 접속 | 웹사이트 방문 | 채팅 인터페이스 + 안내 메시지 |
| 2. Notion 연결 | Notion Integration 토큰 입력 or OAuth | 워크스페이스 연결 확인 |
| 3. 요구사항 입력 | 자연어로 원하는 템플릿 설명 | AI가 의도 분석 |
| 4. 확인 질문 | AI 질문에 답변 | 부족한 정보 보충 |
| 5. 구조 미리보기 | 제안된 구조 검토 + 수정 요청 | JSON Blueprint 표시 |
| 6. 생성 승인 | "생성해줘" 확인 | Notion API 호출 시작 |
| 7. 진행 확인 | 실시간 진행률 확인 | 블록/DB 생성 현황 표시 |
| 8. 결과 수신 | Notion 링크 클릭 → 확인 | 완성된 템플릿 URL 제공 |
| 9. 후속 수정 | "태그 속성 추가해줘" 등 | 기존 페이지에 수정 적용 |

## 2. 핵심 시나리오

### 시나리오 A: 프로젝트 대시보드

```
사용자: 프로젝트 관리 대시보드 만들어줘. 갤러리 뷰로, 카테고리 태그 있고,
       좌측에 캘린더랑 섹션 네비게이션, 주황색 톤으로!

AI: 프로젝트 관리 대시보드를 만들어드리겠습니다. 몇 가지 확인할게요:

    1. 하위 페이지도 필요한가요? (예: ETC, Study 등)
    2. 카테고리 태그 옵션은 어떤 것들이 있나요?
       (예: LLM, Web, Mobile 등)
    3. 갤러리 카드에 커버 이미지를 넣을까요?

사용자: 하위 페이지 3개 (ETC, Project, Study), 카테고리는 LLM/Web/Mobile/Data,
       커버 이미지도 넣어줘

AI: 아래 구조로 생성하겠습니다:

    📁 메인 대시보드
    ├─ 커버: 주황색 톤 이미지
    ├─ 좌측 (30%): 캘린더 + 섹션 링크 (ETC, Project, Study)
    ├─ 우측 (70%): 갤러리 DB (카테고리: LLM/Web/Mobile/Data)
    ├─ 📁 ETC (하위 페이지)
    ├─ 📁 Project (하위 페이지)
    └─ 📁 Study (하위 페이지)

    생성할까요?

사용자: 응 ㄱㄱ

AI: 생성 중...
    ✅ 메인 페이지 생성 완료
    ✅ 프로젝트 DB 생성 (4개 속성)
    ✅ 갤러리 뷰 + 샘플 데이터 5개
    ✅ 칼럼 레이아웃 (좌30/우70)
    ✅ 하위 페이지 3개 생성 + 각각 구조 구축
    ✅ 네비게이션 링크 연결

    완성! 👉 https://notion.so/xxxxx
```

### 시나리오 B: 북마크 사이트

```
사용자: 북마크 정리 사이트 만들어줘. 카테고리별로 분류하고,
       즐겨찾기 기능도 있었으면 좋겠어. 깔끔한 느낌으로!

AI: 북마크 사이트 템플릿을 만들어드리겠습니다.

    카테고리는 어떤 것들이 있나요?
    (예: 커리어, 쇼핑, 교육, 게임 등)

사용자: 커리어, 쇼핑, 교육/툴&디자인, 게임, 노션, 뉴스/매거진, Entertain, 트렌드 서칭

AI: 구조:
    📄 북마크 사이트
    ├─ 안내 콜아웃 (favorite/routine 설명)
    ├─ 좌측: 카테고리 목록 (8개)
    ├─ 우측: 북마크 DB (갤러리 뷰)
    │   ├─ 속성: 이름, URL, 카테고리(select), 즐겨찾기(checkbox), 요일(multi_select)
    │   ├─ 뷰1: favorite (즐겨찾기 필터)
    │   └─ 뷰2: routine (요일 자동 필터)
    └─ 샘플 북마크 10개

    생성할까요?

사용자: 좋아 만들어줘
```

### 시나리오 C: 개인 기록 (Tea Note 스타일)

```
사용자: 차 시음 기록 노트 만들어줘. 귀여운 느낌, 초록색으로.
       종류별 정리하고 즐겨찾기 기능도.

AI: Tea Note 템플릿 만들어드리겠습니다!

    차 종류 옵션을 알려주세요:
    (예: 녹차, 보이차, 말차, 홍차, 허브차 등)

사용자: 녹차, 보이차, 말차, 홍차, 우롱차, 허브차

AI: 구조:
    📄 Tea Note 🍵
    ├─ 커버: 초록색 테마 이미지
    ├─ 사용 설명서 (토글)
    ├─ 좌측: Quick Action + Menu 링크
    ├─ 우측: 시음 기록 DB
    │   ├─ 속성: 이름, 종류(select 6종), 브랜드, 평점(number), 즐겨찾기, 날짜
    │   ├─ 뷰1: 즐겨찾기 (갤러리)
    │   ├─ 뷰2: 전체 (테이블)
    │   └─ 뷰3: 이 달의 차 (갤러리, 날짜 필터)
    ├─ 📁 차 인벤토리 (하위 페이지)
    └─ 📁 일기장 (하위 페이지)

    생성할까요?
```

### 시나리오 D: 회사 신입사원 인수인계

```
사용자: 신입사원 온보딩 템플릿 만들어줘. 하늘색 느낌으로.
       1주차~4주차 체크리스트, 부서별 안내, 인수인계 현황 DB 포함해줘.

AI: 온보딩 템플릿 만들어드리겠습니다.

    1. 부서 목록을 알려주세요:
    2. 인수인계 항목 예시가 있나요?

사용자: 부서는 개발팀, 디자인팀, 마케팅팀, 경영지원팀.
       항목은 DB 접근권한, 코드리뷰 방법, 배포 프로세스 등

AI: 구조 확인:
    📄 신입사원 온보딩 가이드 👋
    ├─ 커버: 하늘색 이미지
    ├─ 환영 콜아웃 (blue_background)
    ├─ 📋 주차별 체크리스트 (1~4주)
    │   ├─ 1주차: 계정 발급, 팀 미팅, 환경 세팅
    │   ├─ 2주차: 코드베이스 탐색, 첫 PR
    │   ├─ 3주차: 독립 태스크 수행
    │   └─ 4주차: 프로젝트 배정
    ├─ 📂 부서별 안내 (2단 칼럼)
    │   ├─ 📁 개발팀 가이드
    │   ├─ 📁 디자인팀 가이드
    │   ├─ 📁 마케팅팀 가이드
    │   └─ 📁 경영지원팀 가이드
    ├─ 📊 인수인계 현황 DB (테이블 뷰)
    │   └─ 속성: 항목, 담당자, 상태, 기한
    └─ 💡 FAQ (토글)

    생성할까요?
```

## 3. 엣지 케이스 & 예외 처리

### 모호한 요청

```
사용자: 노션 만들어줘

AI: 어떤 용도의 노션 템플릿을 만들어드릴까요?

    인기 카테고리:
    • 📊 프로젝트 관리 (대시보드, 칸반)
    • ✅ 습관/목표 트래커
    • 📚 학습/독서 기록
    • 🏢 업무용 (CRM, 회의록, 인수인계)
    • 🔖 북마크/자료 정리
    • 📝 일기/기록 노트

    또는 원하는 내용을 자유롭게 설명해주세요!
```

### 불가능한 요청

```
사용자: 버튼 클릭하면 자동으로 항목 추가되는 기능 넣어줘

AI: 아쉽게도 Notion API로는 버튼 블록 생성이 지원되지 않습니다.

    대안으로 이렇게 해드릴 수 있어요:
    1. 데이터베이스의 "새로 만들기" 버튼 활용 (Notion 기본 기능)
    2. 콜아웃 블록으로 시각적 안내 버튼 생성 (클릭 시 해당 DB로 이동)

    어떤 방법이 좋을까요?
```

### 너무 큰 요청

```
사용자: 회사 전체 ERP를 노션으로 만들어줘. 인사, 재무, 프로젝트,
       전자결재, 자재관리 다 포함해서.

AI: 전체 ERP 규모의 워크스페이스를 한 번에 만들면 품질이 떨어질 수 있어요.

    단계별로 만들어드릴까요?
    1단계: 먼저 메인 대시보드 + 인사관리 모듈
    2단계: 재무 + 프로젝트 모듈 추가
    3단계: 전자결재 + 자재관리 추가

    1단계부터 시작할까요?
```

## 4. 사용자 입력 분석 패턴

### AI가 파악해야 할 정보

| 정보 | 필수 | 예시 | 미입력 시 기본값 |
|------|------|------|----------------|
| 템플릿 용도/주제 | **필수** | "프로젝트 관리", "독서 기록" | AI가 반드시 질문 |
| 색상 테마 | 선택 | "하늘색", "주황색" | 기본 테마 (gray) |
| 하위 페이지 | 선택 | "3개 (A, B, C)" | AI가 용도에 맞게 추천 |
| DB 속성 | 선택 | "카테고리, 날짜, 상태" | AI가 용도에 맞게 추천 |
| 뷰 타입 | 선택 | "갤러리", "칸반" | AI가 용도에 맞게 추천 |
| 샘플 데이터 | 선택 | "예시 5개 넣어줘" | 기본 5개 |
| 레이아웃 | 선택 | "2단 칼럼" | AI가 용도에 맞게 추천 |

### 의도 분류 (Intent Classification)

```
1. 생성 (CREATE)    → "만들어줘", "생성해줘", "제작해줘"
2. 수정 (MODIFY)    → "추가해줘", "바꿔줘", "수정해줘"
3. 질문 (QUESTION)  → "가능해?", "할 수 있어?", "차이가 뭐야?"
4. 확인 (CONFIRM)   → "응", "좋아", "ㄱㄱ", "만들어"
5. 거절 (REJECT)    → "아니", "다시", "그건 말고"
```
